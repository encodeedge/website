### Curriculum Objectives
This lesson covers the core engineering concepts and implementations for:
- The Constant Error Carousel: Additive Cell State Highways (C_t)
- LSTM Gating Mechanics: Forget Gate (f_t), Input Gate (i_t), Output Gate (o_t)
- Simplified Architecture: Gated Recurrent Units (GRUs)

### Overview
Master Hochreiter & Schmidhuber's iconic LSTM architecture designed to preserve memory over hundreds of time steps by replacing destructive matrix multiplications with additive linear highways.

### Key Concepts & Takeaways
- Forget gate sigmoid activations deciding what information to discard from cell state
- Input gate and candidate updates introducing new information
- GRU variations merging cell and hidden states with reset and update gates
