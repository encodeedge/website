### Curriculum Objectives
This lesson covers the core engineering concepts and implementations for:
- Extracting and Plotting Learned First-Layer Convolutional Kernels
- Hooking Intermediate Layer Activations in PyTorch
- Interpreting Hierarchical Feature Abstraction: Edges -> Textures -> Parts -> Objects

### Overview
Peer inside the convolutional black box by visualizing learned weight filters and intermediate activation maps to understand how deep vision models represent visual information.

### Key Concepts & Takeaways
- Low-level filters acting as Gabor-like edge, streak, and color gradient detectors
- Forward hooks in PyTorch capturing internal tensor outputs without modifying model architecture
- Spatial compression and semantic abstraction progression across network depth
