### Curriculum Objectives

This lesson covers the core engineering concepts and implementations for:

* AdaGrad: Adaptive Learning Rates via Cumulative Squared Gradients
* RMSProp: Exponentially Decaying Average of Squared Gradients
* Adam: Adaptive Moment Estimation with Bias Corrections

### Overview

Explore adaptive learning rate algorithms that scale update step sizes individually for each parameter based on historical gradient magnitudes.

### Key Concepts & Takeaways

* Overcoming the aggressive learning rate decay flaw in AdaGrad using RMSProp's moving average
* Adam's combination of first moment (momentum) and second moment (uncentered variance)
* Analytical bias correction factors (1 - beta^t) during early training iterations
