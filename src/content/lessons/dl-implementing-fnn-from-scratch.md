### Curriculum Objectives
This lesson covers the core engineering concepts and implementations for:
- Object-Oriented Neural Network Architecture in NumPy
- Vectorized Forward and Backward Cache Dictionaries
- Numerical Gradient Checking Implementation

### Overview
Implement an extensible, object-oriented multi-layer neural network from scratch in pure NumPy, including automated backpropagation and numerical gradient verification.

### Key Concepts & Takeaways
- Modular class interface: .forward(), .backward(), and .fit()
- Caching layer pre-activations (Z) and activations (A) for clean gradient retrieval
- Implementing numerical finite differences to verify analytical gradients to 1e-7 precision
