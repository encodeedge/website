### Curriculum Objectives
This lesson covers the core engineering concepts and implementations for:
- Deep Feedforward Network Layer Notation
- Weight Matrices & Bias Vector Dimensions
- Batched Forward Propagation via Matrix Multiplication

### Overview
Formalize the forward propagation pass of an L-layer deep neural network into clean, efficient linear algebra matrix equations.

### Key Concepts & Takeaways
- Layer notation: inputs, pre-activations (z), and post-activations (a)
- Dimension matching across layers: W_l has shape (n_l, n_{l-1})
- Batched tensor equations computing predictions for N samples concurrently
